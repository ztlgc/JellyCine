# JellyCine 1.3.6.2 Android 手机定制版（2026-11-09）

发布标签：`v1.3.6.2-android-20261109`。包名 `com.jellycine.app`，版本 `1.3.6.2` / versionCode `1030602`，沿用现有正式签名，可覆盖同签名旧版及此前的 1.3.6.1 测试包。

## 更新内容

- 视频详情评分右侧显示标签摘要，点击可添加或删除多个标签，保存到媒体服务器。兼容 Jellyfin 的 `Tags` 与 Emby 的 `TagItems`；保留完整媒体资料、已有标签标识及字段锁，回读确认后才报告保存成功。修复旧测试包在 Emby 上可能提示“服务器尚未确认这些标签”的字段兼容问题。
- 视频提交删除后立即从本地列表隐藏，后台执行服务器删除并在失败时重试。
- 重整屏幕时间页面与图表：突出实际观看时长，补充日均、视频数和打开次数；视频前五排行可切换时长与打开次数，完善日期/时段筛选、清除操作、中英文时长、小屏大字体布局。同账号同日期范围刷新保留原内容和筛选，失败可保留旧数据并重试。
- 首页统一为媒体入口，保留媒体库、继续播放、接下来及媒体库内容，移除顶部按媒体类型切换与精选轮播。
- 改进媒体库的首次评分展示、封面更新、目录和文件夹刷新；旧快照可先显示再补刷新，过期与手动刷新绕过 HTTP 缓存。播放停止上报成功后读取服务器确认的观看状态，使达到已看阈值的视频及时更新“继续播放”。
- 优化大媒体库与合集加载，复用同一服务器/账号会话内的合集内容并限制并发和缓存规模，刷新失败保留原完整合集；在查询层排除照片，保留文件夹导航。
- 新增五款可切换桌面图标，入口为“设置 → 界面 → 应用图标”。默认采用 02“胶片字母 J”，启动页与应用内品牌图同步更新；桌面图标选择与应用内固定品牌图分别显示。
- 新增启动时更新检查与关于页手动检查；发现新版本后可通过浏览器打开本仓库的 GitHub Release 页面下载安装包。
- 修复 ExoPlayer 音频增益处理器在空输入、重复结束信号与输出尚未消费时的排空处理，保留待输出音频和尾部数据，完善 flush/reset 状态。
