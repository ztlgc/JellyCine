## 已修正

| 区域 | 代码中发现的问题 | 调整 |
| --- | --- | --- |
| 共用 AMOLED 弹窗 | 光晕装饰使用 `fillMaxSize`，参与测量并撑满父布局；宽度上限 880dp，缺少内容整体滚动 | 装饰改为 `matchParentSize`；新增 `PhoneDialog`，在系统安全区域及键盘之外居中，限制面板宽度，内容可滚动 |
| 服务器及用户切换 | 标题、列表和操作之间多处 24–28dp 空白 | 收紧到 16dp，沿用切换时的禁止关闭规则 |
| 选择弹窗 | 行内垂直留白和选项间隔偏大 | 行内垂直留白 14→10dp，选项间隔 10→8dp；选项行最小高度 48dp |
| 播放器轨道及详情轨道选择 | 自定义宽度和固定列表高度，在矮窗口中不能主动给标题留出空间 | 使用共用弹窗；列表按标题之后的剩余空间收缩并滚动 |
| 下载、下载画质、媒体请求 | 多层横向留白压缩正文；下载窗口只滚动列表，短窗口中操作区可能不可达 | 统一外边距和居中规则；下载面板内容整体可滚动，保留列表的高度上限 |
| 播放器更多菜单 | 使用 68/116dp 固定顶边距模拟按钮位置 | 菜单放在“更多”按钮的同一个容器中，随按钮定位 |
| 播放信息浮层 | 允许越过窗口边界，关闭按钮与第一组文字重叠 | 启用窗口裁剪，第一组文字避让关闭按钮，关闭区域从 20→40dp |
| 搜索 | 结果用固定 72dp 避让搜索栏；输入可多行；键盘与悬浮导航竞争空间 | 按搜索栏实际测量高度避让；输入设为单行；增加键盘避让，输入时隐藏底部导航 |
| 首页、收藏、搜索列表 | 用不同的 100/120dp 固定值预留底部空间 | 统一按导航栏高度、外边距和实际系统底部 inset 计算；搜索键盘出现时缩减到 16dp |
| 设置、播放器设置、字幕设置、界面、缓存、关于、下载、服务器信息 | 独立页面没有悬浮底部导航，却预留约 96dp 空白 | 底部内容留白 96→24dp；设置分组与设置行适当收紧 |
| 网络超时及缓存输入弹窗 | 表单与提示文本缺少滚动容器 | 内容可滚动，减少横屏或键盘出现时的裁切风险 |
| 媒体库排序及筛选 | 内部重复处理系统底部 inset；排序行留白偏大；筛选可能只半展开 | 使用底部面板自带的 inset 处理；排序行保留至少 48dp；筛选直接完整展开 |
| 全部媒体及筛选面板 | 标题垂直留白 18–20dp，分组间隔 32dp，底部留白 32dp | 标题垂直留白 12dp，分组间隔 20dp，底部留白 16dp；删除内部重复 inset |
| 影评面板 | 正文只设固定最大高度 | 正文同时受标题之后的剩余空间约束，并可滚动 |
| 普通视频详情 | 横屏仍按屏幕宽度设置最高 520dp 的封面高度 | 横屏封面改为参考窗口高度，范围 200–360dp |

登录表单已有键盘避让及滚动；主要详情、照片查看和屏幕使用时间页面已有滚动或安全区域处理。本次没有进一步压缩它们的正文、封面或图表，也没有调整首页卡片尺寸和卡片之间已收紧的垂直间距。
